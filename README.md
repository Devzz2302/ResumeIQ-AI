# ResumeIQ AI

ResumeIQ AI is a resume screening and candidate matching platform built using Flask, React, and NLP techniques. It helps recruiters analyze resumes, extract skills, compare candidates with job requirements, and provide resume improvement suggestions.

## Features

* Resume upload (PDF/DOCX)
* Skill extraction from resumes
* Candidate-job matching
* ATS compatibility analysis
* Resume quality scoring
* Improvement recommendations
* Recruiter dashboard for candidate evaluation

## Tech Stack

### Backend

* Python
* Flask
* Scikit-learn
* NLTK

### Frontend

* React
* TypeScript
* Material UI
* Vite

## How it Works

1. Upload a resume.
2. Extract skills, education, and experience details.
3. Compare resume content with job requirements.
4. Generate matching scores and recommendations.
5. Display analysis results through an interactive dashboard.

## Installation

### Backend

```bash
pip install -r requirements.txt
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm run build
```
